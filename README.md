# Yuuuuukiu Blog

Personal blog powered by [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) and GitHub Pages.

## Local Preview

```powershell
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000`.

## Writing

Create posts under `_posts` with this filename format:

```text
YYYY-MM-DD-title.md
```
